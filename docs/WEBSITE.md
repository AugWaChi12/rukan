## 1. เป้าหมาย

1. บอกให้เข้าใจใน 5 วินาทีว่า **รู้กัน** คืออะไร — "ไม่เหงา แค่เริ่มทัก"

## 4. Waitlist

### ข้อมูลที่เก็บ

| ช่อง | บังคับ | หมายเหตุ |
| --- | --- | --- |
| อีเมล | ✅ | unique (ลงซ้ำ = อัปเดต ไม่ error) |
| ย่าน / มหาลัย | ✅ | เลือกจากรายการ + "อื่นๆ (พิมพ์เอง)" |
| ช่วงอายุ | ❌ | 18–21 / 22–25 / 26–30 / 30+ (ไม่เก็บวันเกิด) |
| มาหาอะไร | ❌ | เพื่อน / คนคุย / เดท |
| ยินยอมรับข่าวสาร | ✅ | checkbox ไม่ติ๊กไว้ก่อน + ลิงก์ `/privacy` + เวอร์ชันเอกสาร |
| ภาษา, ที่มา (utm) | อัตโนมัติ | วัดผลช่องทางโปรโมท |

### ทางเทคนิค

- ตาราง `private.waitlist` (ไม่เปิด API) + RPC `public.join_waitlist(email, area, age_band, intents, consent_version, locale, utm)` ที่ anon เรียกได้
- RPC ไม่คืนข้อมูลใดๆ นอกจาก `ok` (กันคนเช็คว่าอีเมลไหนเคยลงแล้ว)
- กันสแปม: Cloudflare Turnstile (ฟรี) ตรวจใน Next.js Route Handler ก่อนเรียก RPC + rate limit ต่อ IP
- ยกเลิกรับข่าวสารได้ (ลิงก์ในอีเมล) — ตาม PDPA
- pgTAP: anon เรียก RPC ได้, anon/authenticated อ่านตาราง waitlist ไม่ได้

## 5. เทคนิคอื่นๆ

- **ภาษา:** `/` = ไทย, `/en` = อังกฤษ (`next-intl` หรือ dictionary ธรรมดา) + `hreflang`
- **ธีม:** สว่างเป็นหลัก, section ความปลอดภัยใช้พื้นดำทอง (ไม่มีสวิตช์ธีมบนเว็บโปรโมท)
- **SEO / แชร์:** `metadata` ต่อหน้า, รูป Open Graph 1200×630 (ไทย/อังกฤษ), `sitemap.xml`, `robots.txt`
- **ความเร็ว:** หน้าแรก static ทั้งหน้า (ยกเว้นฟอร์ม), ฟอนต์ผ่าน `next/font` (Prompt + Anuphan), รูปผ่าน `next/image`
- **วัดผล:** Vercel Web Analytics (ไม่มี cookie banner) + event "ลงชื่อสำเร็จ"
- **โดเมน:** `rukan.app` (ยังไม่ได้จด) → Vercel, `www` redirect ไป apex
- ทั้งเว็บต้องใช้ได้ที่จอ 360px, ปุ่มสูง ≥ 44px, contrast ผ่าน 4.5:1
