## 1. แนวคิด

**"ไม่เหงา แค่เริ่มทัก"** — แอปสำหรับคนวัย 18–30 (นักศึกษา + วัยทำงานตอนต้น) ที่อยากมีเพื่อนคุย เพื่อนกินข้าว หรือคนพิเศษ
ขายเรื่อง **ความเหงา/การมีคนคุย** ก่อนเรื่องหาคู่ — ไม่ต้องอายที่เปิดแอป

## 2. ปัญหาของคู่แข่ง → สิ่งที่เราทำต่าง

| ปัญหา (Tinder / Omi / CMB)          | เราแก้ด้วย                                                               |
| ----------------------------------- | ------------------------------------------------------------------------ |
| ตัดสินกันที่หน้าตา                  | **รูปค่อยๆ เปิด** ตามจำนวนข้อความที่คุยกัน + **match จากโพสต์** ใน Space |
| บัญชีปลอม / มิจฉาชีพ                | **ยืนยันเบอร์ + selfie liveness** ทุกคน, ป้ายมหาลัย/ที่ทำงาน (ไม่บังคับ) |
| match แล้วไม่มีใครทัก / โดน ghost   | **match หมดอายุ 48 ชม.**, คำถามเปิดบทสนทนา, ปุ่ม **จบอย่างสุภาพ**        |
| ไม่มีเหตุผลให้เปิดแอปถ้าไม่มี match | **Space** ให้อ่าน/ระบายทุกวัน + **ปัดรอบละ 20 ใบ รีทุก 6 ชม.**           |
| ต้องจ่ายเงินถึงจะเห็นว่าใครชอบ      | ไม่ล็อกฟีเจอร์หลัก หารายได้จากของตกแต่ง + พาร์ทเนอร์ร้านค้า (ภายหลัง)    |
| แอปหาคู่ = ภาพลักษณ์ไม่ดี           | แยกโหมด **เพื่อน / เดท**                                                 |

## 3. ฟีเจอร์

### MVP (เวอร์ชันแรก)

| #   | ฟีเจอร์                  | สรุป                                                                                                                                               |
| --- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1  | **สมัคร + ยืนยันตัวตน**  | Apple / Google / LINE / Facebook / อีเมล → เบอร์ OTP → ข้อมูลพื้นฐาน (18+) → selfie liveness → ป้ายองค์กร (ไม่บังคับ) → ยอมรับกติกา                |
| F2  | **Space (ไม่ระบุตัวตน)** | feed แบบ X: แท็บ ใกล้ฉัน / วัยเดียวกัน / ทั้งหมด, โพสต์ด้วยนามแฝง, ถูกใจ, ตอบกลับ, check-in อารมณ์                                                 |
| F3  | **Bubble**               | ทักเจ้าของโพสต์แบบไม่ระบุตัวตน → ถ้ารับ เปิดแชทนามแฝง → ทั้งคู่กด "เปิดตัว" ถึงเห็นโปรไฟล์จริง                                                     |
| F4  | **ปัด (Swipe deck)**     | ปัดได้ต่อเนื่อง รวมทุกโหมด โควตา Free 20 / Gold 40 ใบต่อรอบ เริ่มนับตอนปัดใบแรก ครบ 6 ชม. รีใหม่ · ปัดขวา = สนใจ, ซ้าย = ข้าม (ฟองสลายไปตามทิศทาง) |
| F5  | **Match + แชท 1:1**      | ชอบกันทั้งคู่ = match, ต้องทักใน 48 ชม., รูปเปิดทีละขั้นตามข้อความ, ปุ่มจบอย่างสุภาพ                                                               |
| F6  | **ความปลอดภัย**          | รายงาน, บล็อก, ตัวกรองเนื้อหา, rate limit, แชร์นัดให้เพื่อน, เตือนกลโกง                                                                            |
| F7  | **ตั้งค่า**              | ภาษา ไทย/English, ธีม สว่าง/ดำทอง/ตามระบบ, ความเป็นส่วนตัว, ลบบัญชี                                                                                |

### หลัง MVP

- **ว่างตอนนี้** — บอกว่าว่างถึงกี่โมง อยากทำอะไร เห็นคนว่างใกล้ๆ (ออกแบบไว้แล้ว แต่ต้องมีผู้ใช้หนาแน่นก่อนถึงจะมีประโยชน์)
- คุยก่อนนอน (สุ่มคุย 1:1 จำกัดเวลา), เพื่อนรับรอง (wingman), ธีมตามช่วงชีวิต, คูปองร้านค้าสำหรับนัดแรก
- จับคู่ด้วยความหมายของคำตอบ (embedding) แทนแค่แท็กตรงกัน

## 4. กลุ่มผู้ใช้ + การเปิดตัว

- อายุ 18–30, เริ่มที่กรุงเทพ
- เปิดตัวแบบ **"ย่านเดียว + มอเดียว"** ก่อน (ใกล้ตัวทีม) ให้คนหนาแน่นพอ match กันได้จริง แล้วค่อยขยาย
- ช่องทาง: เพจ/กลุ่มมหาลัย, TikTok/IG เล่าเรื่องความเหงาแบบไม่ระบุตัวตน (ดึงโพสต์เด่นจาก Space ไปทำคอนเทนต์ได้ — ต้องได้รับอนุญาตก่อน)

## 5. ตัวชี้วัด (ร่าง)

| ตัวชี้วัด                                  | ทำไมสำคัญ                            |
| ------------------------------------------ | ------------------------------------ |
| % คนที่ยืนยันตัวตนครบ หลังสมัคร            | onboarding ยากไปไหม                  |
| คนที่เปิดแอปวันละครั้ง / สัปดาห์ (DAU/WAU) | Space + Daily Drop ดึงคนกลับมาได้ไหม |
| % match ที่มีข้อความแรกภายใน 48 ชม.        | แก้ ghost ได้จริงไหม                 |
| % บทสนทนาที่ถึงขั้นเปิดรูปครบ              | คนคุยกันจริงไหม                      |
| รายงาน / 1,000 ผู้ใช้, เวลาจัดการรายงาน    | ชุมชนปลอดภัยไหม                      |

## 6. ดีไซน์

- สไตล์ **Soft Bubble**: นุ่ม สงบ ดูโต — พื้นขาวอุ่น, พาสเทลหม่นเป็นสีเน้น, ปุ่มทรงเม็ดยา, ฟองแชท (อยู่ระหว่าง "แข็งไป" กับ "น่ารักไป")
- ฟอนต์: Prompt (หัวข้อ) + Anuphan (เนื้อหา)
- ธีม: สว่าง + **ดำทอง** (ทอง `#D6B36A` บนดำอุ่น `#0F0E0D`)
- ภาษา: ไทย + English ตั้งแต่ MVP
