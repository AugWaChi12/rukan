## 1. หลักการ

1. **ทุกคนเป็นคนจริง** — ยืนยันตัวตนก่อนใช้ฟีเจอร์ที่คุยกับคนอื่น
2. **ไม่ระบุตัวตนต่อผู้ใช้ ไม่ใช่ต่อระบบ** — ใน Space คนอื่นไม่รู้ว่าเป็นใคร แต่ระบบรู้ และใช้เมื่อมีการทำผิดกติกาหรือมีคำสั่งตามกฎหมายเท่านั้น
3. **เก็บข้อมูลน้อยที่สุด** — เก็บเฉพาะที่จำเป็น ลบเมื่อหมดความจำเป็น
4. **ปลอดภัยเป็นค่าเริ่มต้น** — ฟีเจอร์ที่เสี่ยง (ตำแหน่ง, รูป) ปิดหรือจำกัดไว้ก่อน ผู้ใช้เลือกเปิดเอง

## 2. ใครใช้ได้

- อายุ **18 ปีขึ้นไป** เท่านั้น (ทั้งโหมดเพื่อนและเดท) — ไม่ต้องดูแลผู้เยาว์ ลดความเสี่ยงทางกฎหมายมาก
- 1 คน = 1 บัญชี (ผูกกับเบอร์โทร)
- ห้ามใช้เพื่อการค้า การตลาด การหาสมาชิก MLM หรือชวนลงทุน
- ผู้ที่เคยถูกแบนถาวร สมัครใหม่ไม่ได้ (เช็คจากเบอร์โทร + ผล selfie)

## 3. ขั้นตอนสมัคร + ยืนยันตัวตน

| ขั้น | อะไร | บังคับ? | ใช้ทำอะไร | เก็บอะไร / นานแค่ไหน |
|---|---|---|---|---|
| 0 | เข้าสู่ระบบ: **Apple / Google / LINE / Facebook** หรือ อีเมล | ✅ | สร้างบัญชี | id จาก provider, อีเมล |
| 1–2 | **เบอร์โทร + OTP** | ✅ | กันบัญชีปลอม/สแปม, 1 คน 1 บัญชี | เบอร์ (hash สำหรับเช็คซ้ำ) จนกว่าจะลบบัญชี |
| 3 | **ชื่อเล่น, วันเกิด, มาหาอะไร** (เพื่อน / คนคุย / เดท) | ✅ | แสดงโปรไฟล์, เช็คอายุ ≥ 18 | วันเกิด (แสดงแค่อายุ), เปลี่ยนวันเกิดเองไม่ได้ |
| 4 | **Selfie liveness** (วิดีโอสั้นตามคำสั่ง เช่น หันซ้าย ยิ้ม) | ✅ ก่อนปัด/แชท | ยืนยันว่าเป็นคนจริง, ไม่ใช่รูปคนอื่น | วิดีโอลบภายใน **30 วัน**, เก็บแค่ผล "ผ่าน/ไม่ผ่าน" + วันที่ |
| 5 | **ป้ายมหาลัย / ที่ทำงาน** (ยืนยันด้วยอีเมลองค์กร) | ❌ | เพิ่มความน่าเชื่อถือ | ชื่อองค์กร + โดเมน, **ไม่เก็บ/ไม่แสดงอีเมลเต็ม** |
| 6 | **ยอมรับกติกาชุมชน** (สรุป 4 ข้อ + ลิงก์ฉบับเต็ม) | ✅ | | วันเวลาที่ยอมรับ + เวอร์ชันของกติกา |

ใช้แอปได้ระดับไหนก่อนยืนยันครบ:

| สถานะ | ทำได้ |
|---|---|
| สมัครแล้ว ยังไม่ยืนยันเบอร์ | ดูหน้าแนะนำเท่านั้น |
| ยืนยันเบอร์แล้ว | อ่าน Space (โพสต์/ส่ง bubble ไม่ได้) |
| ยืนยัน selfie แล้ว | ใช้ได้ทุกอย่าง |

### หมายเหตุทางเทคนิค (สำหรับทีม dev)

- **Supabase Auth** รองรับ Apple, Google, Facebook ในตัว
- **LINE** ไม่มี provider สำเร็จรูปใน Supabase (ณ ที่ทีมทราบ — **ต้องเช็คเอกสารล่าสุด**) ทางเลือก: custom OIDC provider ถ้า Supabase รองรับ, หรือทำ Edge Function แลก token ของ LINE แล้วสร้าง session เอง
- **App Store บังคับ:** ถ้ามี login ด้วย Google/Facebook/LINE บน iOS ต้องมี **Sign in with Apple** ด้วย (App Store Review Guideline 4.8)
- **OTP ทาง SMS:** Supabase Auth phone (ต่อกับผู้ให้บริการ SMS เช่น Twilio / MessageBird / Vonage) — มีค่าใช้จ่ายต่อ SMS, ต้องตั้ง rate limit กันคนยิง OTP
- **Selfie liveness:** ไม่ควรทำเอง ใช้ผู้ให้บริการ เช่น AWS Rekognition Face Liveness, FaceTec, Persona, Veriff — เทียบราคา/ความแม่นยำก่อนเลือก, เรียกผ่าน **Edge Function** (secret key อยู่ฝั่ง server)
- ผลการยืนยันเก็บในตารางแยกที่ **client แก้เองไม่ได้** (เขียนได้เฉพาะ Edge Function ด้วย service role) เช่น `public.verifications (user_id, phone_verified_at, liveness_passed_at, org_badge, …)`

## 4. กติกาชุมชน (Community Guidelines)

### 4.1 ห้ามทุกที่ (Space, โปรไฟล์, แชท)

- ด่าทอ บูลลี่ คุกคาม ขู่ทำร้าย หรือยุให้ผู้อื่นทำ
- เหยียดเชื้อชาติ ศาสนา เพศ เพศวิถี ความพิการ หรืออื่นๆ
- เนื้อหาทางเพศโจ่งแจ้ง ส่งรูปโป๊/อวัยวะเพศโดยอีกฝ่ายไม่ได้ขอ, ชวนหรือเสนอบริการทางเพศ
- เนื้อหาเกี่ยวกับผู้เยาว์ในทางเพศ (**แบนทันที + รายงานเจ้าหน้าที่**)
- หลอกลวง: ชวนลงทุน, ขอยืมเงิน, ขอให้โอน, romance scam, ฟิชชิ่ง
- ปลอมตัวเป็นคนอื่น, ใช้รูปคนอื่น
- ขายของ โฆษณา ชวนเข้ากลุ่ม หรือดึงคนออกไปแอปอื่นเพื่อการค้า
- ยาเสพติด อาวุธ การพนัน หรือสิ่งผิดกฎหมาย
- ส่งเสริมการทำร้ายตัวเอง (ดู 4.4)

### 4.2 กฎเฉพาะของ Space (โพสต์ไม่ระบุตัวตน)

- **ห้ามระบุตัวคนจริง** — ชื่อ-นามสกุล, ชื่อเล่น + คณะ/บริษัทที่รู้ว่าเป็นใคร, รูป, ข้อมูลติดต่อ, ที่อยู่ (กัน doxxing และหมิ่นประมาท)
- ห้ามโพสต์ข้อมูลส่วนตัวของตัวเองที่ระบุตัวได้ (เบอร์, LINE ID, IG) — ปกป้องผู้ใช้เอง และกันขายของ
- ห้ามแฉ/กล่าวหาคนหรือองค์กรที่ระบุตัวได้ แม้จะเป็นเรื่องจริง → ให้ใช้ช่องทางที่ถูกต้อง
- ระบายได้ เล่าเรื่องตัวเองได้ อวดได้ — แค่ต้องไม่ทำร้ายใคร

### 4.3 Match และแชท

- ปฏิเสธได้เสมอ — "ไม่" คือ "ไม่" ห้ามตื๊อ ห้ามสร้างบัญชีใหม่มาทักซ้ำหลังถูกบล็อก
- ห้ามขอรูปที่ไม่เหมาะสม ห้ามกดดันให้เปิดรูป/เปิดเผยข้อมูลก่อนที่อีกฝ่ายพร้อม
- ห้ามแคป/เผยแพร่แชทของคนอื่นเพื่อประจาน

### 4.4 เรื่องที่ต้องช่วย ไม่ใช่ลงโทษ

- ถ้าโพสต์มีสัญญาณทำร้ายตัวเอง → **ไม่ลบทันที** แต่แสดงช่องทางช่วยเหลือให้ผู้โพสต์ (เช่น **สายด่วนสุขภาพจิต 1323**) และส่งให้ทีมดูแล
- ข้อความ "เหงา", "เศร้า" เป็นเรื่องปกติของแอปนี้ — ห้ามระบบกรองจนคนไม่กล้าระบาย

## 5. การบังคับใช้ (Enforcement)

| ระดับ | ตัวอย่าง | ผล |
|---|---|---|
| 1 · เล็กน้อย | หยาบคาย, สแปมเล็กน้อย | ซ่อนโพสต์ + **เตือน** |
| 2 · ซ้ำ / ปานกลาง | ทำผิดซ้ำ, คุกคาม, ระบุตัวคนจริงใน Space | **ระงับชั่วคราว** 3–30 วัน (ห้ามโพสต์/แชท) |
| 3 · ร้ายแรง | หลอกโอนเงิน, ปลอมตัว, ส่งรูปโป๊ไม่ยินยอม, ขู่ทำร้าย | **แบนถาวร** (เบอร์ + ผล selfie ห้ามสมัครใหม่) |
| 4 · ผิดกฎหมายร้ายแรง | เกี่ยวกับผู้เยาว์ในทางเพศ, ค้ามนุษย์ | แบนถาวร + เก็บหลักฐาน + **แจ้งเจ้าหน้าที่** |

- ทุกการลงโทษต้องบอกผู้ใช้ว่า **ผิดข้อไหน** และ **อุทธรณ์ได้** (ภายใน 14 วัน, คนตรวจซ้ำต้องไม่ใช่คนเดิม)
- เก็บประวัติการลงโทษไว้เพื่อดูการทำผิดซ้ำ

### การรายงาน + บล็อก

- กด **รายงาน** ได้ทุกโพสต์, ทุกโปรไฟล์, ทุกข้อความ — เลือกเหตุผล + ใส่รายละเอียดได้
- กด **บล็อก** ได้ทันที: อีกฝ่ายไม่เห็นเราอีกทั้งใน Space, ปัด, ว่างตอนนี้ และแชทจะถูกปิด — **ไม่แจ้งให้อีกฝ่ายรู้**
- ผู้รายงานไม่ถูกเปิดเผยตัวตนต่อคนที่ถูกรายงาน
- เป้าหมายเวลาตอบสนอง: ระดับ 3–4 ภายใน **24 ชม.**, อื่นๆ ภายใน 72 ชม.

### การกลั่นกรอง (Moderation)

- **อัตโนมัติก่อนโพสต์:** กรองคำหยาบรุนแรง, เบอร์โทร/LINE ID/ลิงก์, รูปโป๊ (ใช้บริการตรวจรูป) — ถ้าสงสัยให้รอคนตรวจก่อนเผยแพร่
- **Rate limit:** จำกัดจำนวนโพสต์, bubble, การปัด และข้อความต่อชั่วโมง กันสแปม
- **ทีมคน:** ช่วงแรกทีมผู้ก่อตั้งดูเอง → เมื่อโตขึ้นต้องมีคนดูแลประจำ

## 6. ความเป็นส่วนตัว (PDPA)

### 6.1 ข้อมูลที่เก็บ และฐานทางกฎหมาย

| ข้อมูล | ฐานทางกฎหมาย (PDPA) | หมายเหตุ |
|---|---|---|
| บัญชี, เบอร์, วันเกิด | สัญญา (จำเป็นต่อการให้บริการ) | |
| โปรไฟล์, รูป, คำตอบบนการ์ด | สัญญา | ผู้ใช้เลือกใส่เอง |
| **ข้อมูลใบหน้า (selfie liveness)** | **ความยินยอมโดยชัดแจ้ง** | เป็น **ข้อมูลชีวภาพ = ข้อมูลอ่อนไหว (มาตรา 26)** ต้องขอแยก, ถอนได้, ลบภายใน 30 วัน |
| เพศ / ความสนใจทางเพศ (โหมดเดท) | **ความยินยอมโดยชัดแจ้ง** | อาจถือเป็นข้อมูลอ่อนไหว (พฤติกรรมทางเพศ) — ให้เลือกไม่ระบุได้ |
| ตำแหน่ง (ว่างตอนนี้) | ความยินยอม | ขอเฉพาะตอนเปิดใช้ "ว่างตอนนี้", **ไม่เก็บพิกัดละเอียด** — เก็บแค่ย่าน/ระยะโดยประมาณ, หมดอายุเมื่อปิดสถานะ |
| แชท, โพสต์ | สัญญา | |
| log การใช้งาน, รายงาน | ประโยชน์โดยชอบด้วยกฎหมาย (ความปลอดภัย) | |

### 6.2 ใครเห็นอะไร

| ข้อมูล | ผู้ใช้อื่น | ระบบ/ทีมดูแล |
|---|---|---|
| ตัวตนจริงของคนโพสต์ใน Space | ❌ ไม่มีวันเห็น | ✅ เมื่อตรวจการรายงาน/คำสั่งศาลเท่านั้น (มี log ว่าใครเปิดดู) |
| เบอร์, อีเมล, วันเกิด | ❌ (เห็นแค่อายุ) | ✅ |
| รูปโปรไฟล์ | ค่อยๆ เปิดให้คนที่ match เท่านั้น | ✅ |
| ตำแหน่ง | เห็นแค่ระยะโดยประมาณ / ชื่อย่าน | ย่านล่าสุดเท่านั้น |

### 6.3 สิทธิ์ของผู้ใช้

- ขอดูข้อมูล / ขอสำเนา (export) / แก้ไข / ลบบัญชี / ถอนความยินยอม — ทำได้ **ในแอปเอง** (หน้า ตั้งค่า → ความเป็นส่วนตัว)
- ลบบัญชี: ลบโปรไฟล์ทันที, ข้อมูลอื่นลบภายใน 30 วัน — **ยกเว้น** ข้อมูลที่ต้องเก็บตามกฎหมาย หรือหลักฐานการทำผิดร้ายแรง (เก็บแยก จำกัดคนเข้าถึง)
- ต้องมีช่องทางติดต่อเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) เมื่อเข้าเกณฑ์ที่กฎหมายกำหนด

### 6.4 ระยะเวลาเก็บ (ร่าง)

| ข้อมูล | เก็บนาน |
|---|---|
| วิดีโอ selfie | ≤ 30 วัน (เก็บแค่ผลการตรวจ) |
| แชทของ match ที่หมดอายุ/ยกเลิก | 90 วัน แล้วลบ (เผื่อมีการรายงานย้อนหลัง) |
| โพสต์ Space ที่ผู้ใช้ลบ | ซ่อนทันที, ลบจริงภายใน 30 วัน |
| log จราจรทางคอมพิวเตอร์ | ≥ 90 วัน ตาม พ.ร.บ.คอมพิวเตอร์ (**ทนายต้องยืนยันว่าใช้กับเราอย่างไร**) |
| หลักฐานการทำผิดระดับ 3–4 | ตามที่ทนายแนะนำ |

## 7. ฟีเจอร์ความปลอดภัย

- **เปิดรูปทีละขั้น** — ลดการตัดสินจากหน้าตาและการเอารูปไปใช้ในทางที่ผิด
- **ห้ามแคปหน้าจอแชท/รูป** (ทำได้บนบางระบบ) + แจ้งเตือนเมื่ออีกฝ่ายแคป
- **แชร์นัดให้เพื่อน** — ส่งรายละเอียดว่าเจอใคร ที่ไหน กี่โมง ให้คนที่ไว้ใจ
- **แนะนำจุดนัดที่ปลอดภัย** (ที่สาธารณะ คนเยอะ)
- **ระยะห่างโดยประมาณ** ไม่แสดงตำแหน่งจริง ไม่มีแผนที่
- **เตือนกลโกง** — ถ้าข้อความมีคำว่า โอนเงิน, ลงทุน, crypto, ยืมเงิน → แสดงคำเตือนให้ผู้รับ
- **match หมดอายุ 48 ชม.** + **ปุ่มจบอย่างสุภาพ** — ลดการตื๊อและ ghost
